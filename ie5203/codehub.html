About

This page contains computer files and source code (Excel, Netica, DPL, YAAHP, Python scripts, Jupyter notebooks, etc) that are covered in the Decision Analysis classes.

DApy Python Module

DApy is a set of computational tools in Python for performing some of the decision analysis tasks that were covered in class. Example code for each chapter are provided to demostrate how to access the DApy classes and methods.
